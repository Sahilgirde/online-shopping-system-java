# Online Shopping System

This is my Java project. It is a console based online shopping app where a user can see products, add them to cart and buy them.

## What it can do

- Show all products
- Search a product by name
- Add and remove items from cart
- Show cart with total price
- Checkout using UPI, Card or Cash on Delivery
- Print order receipt

## Concepts used

- Abstract class
- Inheritance (multilevel and hierarchical)
- Method overriding and polymorphism
- Encapsulation
- static and final
- Array
- for, while, switch, if-else

## Packages

- product - Product, Electronics, Clothing, Laptop, Mobile, Shirt
- cart - Cart, CartItem
- customer - Customer
- payment - Payment, UPIPayment, CardPayment, CashOnDelivery
- order - Order
- main - APPMain

## How to run

Open the project in Eclipse and run `APPMain.java`.
